# 05TEAM Reporteador — Supabase v1

Conectado al proyecto Supabase `05team-reporteador`.

Incluye:
- Días ilimitados.
- Varias actividades por día.
- Módulo por actividad y avance por 6 módulos.
- Fotos desde cámara o galería/archivos.
- PDF por día y acumulado.
- Vista cliente mediante enlace con token.
- Datos y fotos sincronizados entre dispositivos con Supabase.
